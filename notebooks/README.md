# Notebooks

All Jupyter notebooks now live under this folder and are grouped by intent:

- `core/`: canonical reference notebooks that describe the main implemented methods.
- `examples/`: user-facing walkthroughs that exercise stable repository workflows.
- `experiments/`: exploratory or generative studies that are useful but not part of the main runtime path.
- `data/`: notebooks focused on dataset inspection or quality diagnostics.
- `vae/`: VAE-specific exploratory notebooks preserved outside the legacy script tree.

The runtime code path remains in `psd_compression/` and `VAE_implementation/`; notebooks are intentionally kept separate so the source tree stays easier to navigate.
